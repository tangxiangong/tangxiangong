## 🔭 Main Projects

<div align="center">
<h3><a href="https://github.com/tangxiangong/diffusionx">DiffusionX</a></h3>
<p>A Rust library for random number generation and stochastic process simulation, with parallel computation and optional GPU acceleration.
</p>
<p align="center">
<a href="https://crates.io/crates/diffusionx"> <img alt="Crates.io Version" src="https://img.shields.io/crates/v/diffusionx?style=for-the-badge"> </a>
<a href="https://docs.rs/diffusionx"> <img alt="docs.rs" src="https://img.shields.io/docsrs/diffusionx?style=for-the-badge"> </a>
<img alt="License: MIT OR Apache-2.0" src="https://img.shields.io/crates/l/diffusionx?style=for-the-badge">
<img alt="Downloads" src="https://img.shields.io/crates/d/diffusionx?style=for-the-badge">
</p>
</div>

**Key Features**:

- Random sampling from normal, uniform, exponential, Poisson, and α-stable distributions
- Brownian and fractional Brownian motion, Lévy processes, Ornstein–Uhlenbeck dynamics, random walks, and more
- Statistical moments, first-passage times, and time-averaged mean squared displacement
- Optional CUDA or Metal acceleration for moment calculations on supported processes and α-stable random sampling
- Trait-based interfaces for custom processes and optional trajectory plotting with [Plotters](https://github.com/plotters-rs/plotters)

<h3><a href="https://github.com/tangxiangong/bibcitex">
    <img src="assets/bibcitex.png" alt="BibCiTeX" width="100" height="100"/>
</a></h3>
<p>BibCiTeX is a BibTeX bibliography and citation tool with a shared Rust core and native macOS and Windows clients.
</p>
<p>
    <a href="https://github.com/tangxiangong/bibcitex/releases">
      <img src="https://img.shields.io/github/v/release/tangxiangong/bibcitex?style=for-the-badge&logo=github&color=blue" alt="GitHub Release">
    </a>
    <a href="https://github.com/tangxiangong/bibcitex/blob/native/LICENSE-MIT">
      <img src="https://img.shields.io/badge/License-MIT%20OR%20Apache--2.0-blue?style=for-the-badge" alt="License">
    </a>
  </p>
</div>

**Key Features**:

- Manage BibTeX libraries and browse reference details and source entries
- Ordinary and advanced search with field filters, Boolean queries, and colored tags
- Single and batch citation copying in key, LaTeX, or Typst format
- Cross-application citation search and pasting through the compact Helper
- Available for macOS (Apple Silicon & Intel) and Windows (ARM64 & x86_64)
